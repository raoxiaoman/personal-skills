# 跨设备可移植

目标是在声明的设备契约内执行；不满足时报告环境阻塞，不静默走错分支。只在一台设备验证过的结果仍有效，但不能证明其他语言、布局或 ROM 已覆盖。

## 设备绑定

仅使用当前 `ANDROID_SERIAL`。`resolve_serial` 校验显式参数是否与绑定一致，并用 `adb -s "$ANDROID_SERIAL" get-state` 确认可用；未绑定或不可用时停止，不列设备自动选取。换设备先明确变更绑定，再记录契约，不能把历史设备矩阵当作当前绑定。

Maestro 和 ADB 使用同一目标，同一设备不并发；运行前确认没有其他任务正在操作该设备，不擅自终止未知进程。

## 语言与选择器

同批历史设备曾分别返回 `zh-CN`、`en-AT`、`zh-Hans-CN`，说明不能从一台设备语言推断全部环境。选择器优先级：

1. 稳定 resource-id。
2. 稳定容器的层级关系；使用 index 前确认顺序契约。
3. 产品明确不本地化的固定文案。
4. 只覆盖目标语言的正则，例如 `text: "(画中画|Picture in Picture)"`。
5. 当前界面验证过的坐标降级，并注明如何重新测量。

fixture 目录名等可控文本可固定语言；系统或应用本地化文案不能未经说明写死。层级缺少稳定标识时记录设备或语言限制，不假装通用。

## 屏幕、窗口与布局

- dump 的 `bounds` 是当前界面的像素，不能复制到其他设备直接使用。
- 百分比减少分辨率耦合，不解决单栏变双栏、控件移位、遮挡或分屏问题。优先语义定位，坐标降级需重新确认布局。
- `wm size` 的正常输出可同时有 Physical 和 Override；模板优先明确的 Override，否则 Physical。方形屏幕是合法尺寸，未知或歧义输出应失败。
- 屏幕尺寸不等于应用可用窗口，也不能据此证明旋转、显示选择、折叠态或多窗口状态。屏幕换算点击仅用于已确认的全屏与显示状态。
- 历史 Maestro 2.10.0 对小数百分比出现过解析错误；优先用整数，其他版本按实际结果验证。
- 密度和布局可能改变可点区域；不要单纯降低可见性阈值来掩盖选错元素或被遮挡。

## 系统命令与网络

历史 Android 12/16 环境观察到 `svc` 的 help 未列出全部可用子命令；不能只靠 help 或版本号断定能力。以实际执行与回读为准，记录目标 ROM 的限制。

Wi-Fi 实现仅维护在 `templates/device-android.sh`：

- `device_wifi_state <serial>` 输出原始开关的 `0` 或 `1`；其他值或读取失败返回非零。
- `device_wifi <serial> <on|off>` 优先 `cmd wifi`，必要时回退 `svc wifi`，随后回读。命令失败或状态不符不能伪装成功。
- `restore_wifi_on_exit <serial>` 在切换前保存原值，正常和异常退出均恢复；原本关闭就保持关闭。已有 EXIT trap 时显式组合，不覆盖。
- Wi-Fi 关闭不代表完全断网；蜂窝、VPN、以太网或其他承载网络可能仍工作。场景需要离线时另验实际连通性，缺少安全构造手段就标未执行，不扩大模板权限。

开发者选项、动画缩放、方向和输入法等状态同样要记录原值、在授权内修改并回读恢复。shell 使用 `set -euo pipefail`，关键调用显式处理失败；`set -e` 在条件和子 shell 中有例外，不能替代错误分支。

## 时序与 fixture

- 更快设备可能缩短竞态时间窗，更慢设备可能超过 timeout。优先用可控素材与状态构造前置，不依赖设备碰巧慢。
- timeout 记录依据；动画缩放影响等待，只有获授权才修改，并恢复原值。
- fixture 不随脚本自动到新设备；核对专属目录、素材身份与媒体库收录，不能只检查文件名。
- 厂商后台清理、省电策略、通知权限和自启动策略会改变后台场景，报告验证过的 ROM 和状态。

## 设备矩阵

按目标风险选择设备，不机械要求固定台数。涉及本地化、平板、折叠或厂商行为时覆盖对应差异；无法覆盖时明确限制。

记录 serial、型号、SDK、ROM、语言、屏幕与密度、应用窗口/折叠态、fixture、关键开关原值和场景结果。设备限定场景单列，说明其他设备是跳过、人工还是未执行。
