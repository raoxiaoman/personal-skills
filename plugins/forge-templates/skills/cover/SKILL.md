# 封面模板制作

调用入口：`forge-templates:cover`。把设计转换为可校对的初始配置，不承诺任意 Figma 设计都能精确还原。

## 按任务进入

只执行本次请求涉及的阶段，不把 Figma 抓取、设备操作或发布设为所有任务的前置。

| 当前任务 | 入口 |
|---|---|
| 从设计生成初始模板 | [workflow.md](references/workflow.md) 的“准备与生成” |
| 已有 App 导出，需要合并 | 同文件“合并导出”，不重跑 Figma |
| 已有配置，需要打包或检查 | 同文件“打包与本地校验” |
| 请求真机校对 | 同文件“设备验证”，先确认独立授权 |
| 准备或执行发布 | 同文件“发布”，资源与总配置分开授权 |

修改配置、处理配对异常或解释校验结果前，读 [config-contract.md](references/config-contract.md)。

## 先固定边界

- 确认当前业务项目、模板编号、输入来源、目标阶段和输出位置；不把 VideoGuru 与 YouCut 的目录、包名、域名混用。
- 本地产物放在插件与业务仓库之外，使用本功能名下的独立父目录，例如 `/tmp/forge-templates-cover/<任务>/`。
- 每轮使用新的输出文件或目录；不覆盖输入，不清空旧 build，不把技能内 `tmp/` 或历史产物打进包。
- 制作、设备写入、安装启动、云端上传、总配置更新分别确认权限；制作授权不包含其余操作。
- 默认只处理本地文件。本次没有设备或上传授权时，不调用设备、不访问远端，也不自动写 App 私有目录。

## 最小执行规则

1. 生成器必须接收竖屏与横屏输入，并要求元数据显式提供 `templateNum`、`fontDir`、`stickerDir`、`fonts` 映射；不继承旧项目路径。
2. `reference/blueprint.json` 只是旧项目字段骨架，不证明当前客户端兼容；正式使用须按宿主源码或真实导出核对。
3. 几何换算、文字合并、尺寸背景过滤和贴纸贪心匹配都是启发式。阅读 `conversion_report.json` 中的剔除候选、对应关系与待确认项。
4. 横竖屏文字数量相同，横竖屏贴纸数量相同；文字与贴纸不必同数量。按样式 ID 核对文字内容和贴纸文件引用，歧义不能记为正确。
5. Figma 脚本只读。执行前遵循当前服务的会话要求，每次 `use_figma` 前加载 `figma-use`；仅本地任务不调用 Figma。
6. 嵌套文字组必须递归识别文字，不能整体当图片；混合样式和不可表达效果停止自动转换，交人工处理。
7. SVG 使用已有 `rsvg-convert`，不自动安装、不自动删除背景，拒绝外部引用；PNG 有 alpha 通道不等于视觉透明。
8. 保留 App 手调导出：完整四组整体采用；部分导出只替换指定方向，保持另一方向，始终写新文件。
9. 稳定沿用 `stickerK` 编号；先核对配置、字体和全部素材，再创建新打包目录。不得按目录顺序重新编号。
10. 本地校验只覆盖核心一致性与包内容，不等于完整 App schema、当前客户端兼容或视觉验收。

## 工具入口

命令统一使用 `python3 -I -B '<技能目录>/scripts/<脚本>.py'`，将占位符替换为本技能实际绝对路径；参数和示例见 workflow。

| 脚本 | 职责 |
|---|---|
| `figma_dump.js` | 在获准的 Figma 会话内只读导出图层数据 |
| `build_config.py` | 生成四组初始配置与 `conversion_report.json` |
| `rasterize_svg_assets.py` | 本地 SVG 栅格化 |
| `merge_export.py` | 合并完整或指定方向的 App 导出 |
| `package_template.py` | 检查素材并生成新资源包 |
| `validate_template.py` | 本地核心检查；可选显式 HTTPS HEAD 检查 |

## 交付说明

列出输入、输出、模板编号、素材映射及待人工确认项。按实际证据标明验证层级：

- **本地核心检查**：配置关系、素材引用、zip 清单及包内配置匹配。
- **宿主与视觉验收**：说明实际客户端、横竖屏校对和导出证据；未执行则明确标记。
- **远端可达性**：显式启用的 HTTPS HEAD 只证明当时可达，不证明内容、CDN 刷新或客户端下载成功。
- **发布状态**：分别报告模板资源与总配置，不能从本地通过推导“发布完成”。
